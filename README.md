# 🎯 OKR GoalZilla Frontend

A modern **frontend application** for tracking Objectives and Key Results (OKRs) — built with **TypeScript**, **React**, and **Vite**.
Part of the *GoalZilla* suite, this project provides an intuitive UI for managing goals and key results effectively.

## 🚀 Features

- 📊 **Dashboard view** to visualize OKRs
- 🗂️ **CRUD operations** for objectives and key results
- ⚡ **Fast and responsive UI** with React + Vite
- 🧪 Structured for clean component development

## 🛠️ Getting Started

### Prerequisites

Install these tools before running the project:

- **Node.js** (v18+ recommended)
- **npm**


### Installation

1. Clone the repository

```bash
git clone https://github.com/Aditya-kumar-sah/OKR_GoalZilla_Frontend.git
```

2. Navigate into the project

```bash
cd OKR_GoalZilla_Frontend
```

3. Install dependencies

```bash
npm install
```

4. Run the application (development mode)

```bash
npm run dev
```
